# Welcome artwork

`city-walk.webp` is original AI-generated artwork created for Muse’s fictional weekend city-walk example. It does not depict a specified real location or reproduce another product’s assets.

The source image was generated with OpenAI image generation and encoded as WebP for use in the application. The sample copy and layout are authored for this project.

`offline-poster.svg` is an original typographic composition, with Inter letterforms converted to paths for consistent rendering. It accompanies the muted street photograph in the OFFLINE moodboard.
