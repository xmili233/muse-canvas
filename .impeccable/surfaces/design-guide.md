# Design guide

Target: src/components/DesignGuide.tsx
Mode: Read

用户在面试时展示项目，访客需要快速了解架构并按主题深入。使用已确认的 Fumadocs 阅读结构、现有 Muse 视觉系统。入口暂定画板头部右侧「设计讲解」。

首屏直接说明 Agent 的作用、处理链路和实现边界，去除自我介绍与重复概述。章节包括概览、Agent 循环、上下文工程、工具设计、Skill 技能、记忆、知识库、权限与安全、评估与观测、实现与取舍；每章开头说明当前演示的实现程度，先列「怎么设计」，再按相同编号说明「为什么这样设计」，章末列参考资料。Markdown 支持表格、代码与 Mermaid。设计方案明确标记，不提供假安装操作。

弹窗不设左侧栏，所有章节连续阅读，右侧本页目录定位到内容。保留 URL 段落定位和关闭，顶部无分隔线。去除搜索、全屏、复制、状态标签、图表工具条和上下章导航。移动端使用内容跳转选择框与单列正文。不得清空访客已有数据。
