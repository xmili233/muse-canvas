Muse 是一个可编辑画板与 Agent 交互演示。当前版本使用浏览器内的规则生成示例建议，不连接真实模型。

```mermaid
flowchart LR
  A[画板与问题] --> B[本地模拟]
  B --> C[便签预览]
  C -->|用户确认| D[加入画板]
```

## 核心结构

- **画板**：组织文字、图片和连线。
- **Agent 演示**：根据问题类型和画板文字生成示例便签。
- **本地数据**：画板、对话与草稿保存在 localStorage。

## 演示范围

无需账号或额外配置，即可体验提问、取消、预览和添加便签。示例结果用于说明交互流程，不代表模型推理能力。

工具扩展与通用权限仍是设计方案，在对应章节中说明。
